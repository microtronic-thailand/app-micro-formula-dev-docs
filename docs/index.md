# MicroAccount Developer Documentation

คู่มือสำหรับนักพัฒนาในการจัดการและพัฒนาต่อยอดระบบ MicroAccount

## Tech Stack
- **Frontend**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS & Shadcn UI
- **Database**: PostgreSQL (Local Docker / Supabase)
- **Language**: TypeScript

## โครงสร้างโปรเจกต์
ระบบถูกออกแบบให้เป็น Modular เพื่อการพัฒนาที่ยืดหยุ่นและการซิงค์ข้อมูลแบบ Off-line First
